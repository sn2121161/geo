对中国中小企业来说，“货已到港”只是物流节点，不是通关结果。进入欧盟后，货物要先被置于相应海关程序；计划在欧盟销售的货物，通常需要申请“自由流通放行”。

真正容易出问题的不是少盖一个章，而是三套信息没有对上：报关数据说的是一件货，发票和箱单说的是另一件货，产品标签、说明书和测试文件又说不清这件货能否在欧盟销售。

## 先理解两条规则线

**海关法典管“如何入境”：** 《欧盟海关法典》（UCC）要求进口货物进入海关程序。标准海关申报必须载明适用于该程序的全部必要数据；申报时，申报人应已持有并能向海关提供所需支撑文件。

**产品法规管“能否放行并销售”：** 海关不只核税。对疑似不符合欧盟产品规则或存在风险的货物，海关会与市场监督机构协作；后者可要求不予自由流通放行。放行本身也不等于产品已经被认证合规。

## 发货前先确定四个角色

| 角色 | 发货前必须确认的事 |
| --- | --- |
| 中国出口商／卖家 | 商品真实成分、用途、成交价格、供应链证据是否完整 |
| 欧盟进口商 | 是否在欧盟设立、是否持有有效 EORI、是否愿意承担进口与产品合规责任 |
| 报关代表 | 是直接代表还是间接代表；由谁提供商品编码、价值、原产地与许可证资料 |
| 承运人／货代 | 谁提交入境安全与安保数据，何时需要补充运单、舱单或其他运输信息 |

不要用“欧洲仓”“平台仓”替代角色确认。仓库地址不当然等于进口商；平台也不当然替卖家承担申报或产品合规义务。

## 报关资料怎样填，才不会前后矛盾

下面是中小企业向欧盟进口商／报关代表交付资料时最实用的填写原则。实际电子申报字段、代码与提交系统由进口国和具体程序决定，应以当地海关和报关代表的要求为准。

| 文件或数据 | 应写什么 | 常见错误 |
| --- | --- | --- |
| 商业发票 | 买卖双方完整名称与地址、发票号和日期、真实成交币种与金额、逐项品名、数量、单价、贸易术语、原产地 | 用“样品”“杂货”“配件”等笼统品名，或低报价格 |
| 装箱单 | 每箱包装号、每个 SKU 的数量、毛重、净重、外箱尺寸和总箱数 | 与发票数量、运单件数不一致 |
| 商品描述与编码 | 可识别的材质、功能、用途、型号和品牌；由进口商／报关代表据此核对 HS／CN／TARIC 编码 | 先按低税率编码报价，后用产品照片补解释 |
| 原产地资料 | 非优惠原产地与任何优惠原产地证明应一致，并能追溯生产地 | 把发货地当作原产地，或把供应商口头承诺当证明 |
| 运输文件 | 运单、提单或航空运单上的收发货人、件数、重量与箱单对应 | 收件人和进口申报主体完全不同且无授权链 |
| 产品合规文件 | 适用品类的 EU 符合性声明、技术文件、测试报告、标签／说明书、欧盟责任人信息及专项许可 | 只发一份过期报告，型号、工厂或批次对不上 |

## 三个“填写动作”比模板更重要

1. **用可验证的品名：** 例如写“额定 20 W、用于室内照明的 LED 台灯，型号 X”，而不是“灯具”或“电子产品”。品名要能支持编码、监管判断与风险筛查。
2. **让金额回到交易事实：** 发票金额、付款记录、合同或订单、平台成交记录应能解释同一笔交易。不要为了税费把报关价值与真实成交价格割裂。
3. **让型号成为共同索引：** 发票、箱单、产品标签、说明书、测试报告和符合性声明都应能定位到相同型号或明确的型号系列。找不到共同索引，海关抽查时就很难解释。

## 哪些产品需要再加一层资料

**受 CE 规则约束的产品：** 例如部分电器、玩具、机械、个人防护用品。除申报资料外，要按适用法规准备符合性评估、EU 符合性声明、技术文件、标识和说明书。

**食品接触材料：** 例如塑料杯、餐盒、保鲜盒。应核实材料规则、迁移测试、书面合规声明和用途限制；不能以“食品级”宣传语替代文件。

**化学品、电池、木制品、动植物产品或受配额／许可证限制的商品：** 还可能涉及 REACH、危险品运输、检疫、木材、环境或专项进口许可。先用商品编码和目的国在欧盟官方数据库核对，再订舱。

## 中小企业行动清单

1. **在打样阶段建档：** 为每个 SKU 建立“产品身份证”，记录型号、材质、用途、工厂、图片、适用法规和责任人。
2. **在报价阶段确认进口模式：** 写清谁是欧盟进口商、EORI 由谁提供、谁委托报关代表、税费由谁承担。
3. **在装运前做三单比对：** 商业发票、装箱单和运单草稿逐项核对品名、型号、数量、重量、收发货人和贸易术语。
4. **在申报前交付合规包：** 把产品文件连同发票与箱单发给进口商／报关代表，留出补件与核对时间。
5. **在扣留时先查“哪条规则”：** 记录海关或主管部门引用的法规、货物项次和期限；不要只问“还能不能放行”。
