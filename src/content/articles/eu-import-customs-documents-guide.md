“货已到港”不等于通关。准备在欧盟销售的货物，通常要办理自由流通放行；在此之前，货物先进入相应的海关程序。

实务里，麻烦往往出在资料对不上。申报数据是一套说法，发票和箱单是另一套，标签、说明书和测试文件又指向别的型号。海关查的就是这种断裂。

## 先理解两条规则线

**海关法典管“如何入境”：** 《欧盟海关法典》（UCC）规定，进口货物要进入海关程序。标准申报应包含该程序需要的数据；提交申报时，申报人手里就应有支撑文件，并能按要求交给海关。

**产品规则管“能否销售”：** 海关不只看税。货物疑似不符合欧盟产品规则，或被认为有风险时，海关会把信息交给市场监督部门。主管部门可以要求不予自由流通放行。即便已经放行，也不等于产品获得了合规认证。

## 发货前先确定四个角色

| 角色 | 发货前必须确认的事 |
| --- | --- |
| 中国出口商／卖家 | 商品真实成分、用途、成交价格、供应链证据是否完整 |
| 欧盟进口商 | 是否在欧盟设立、是否持有有效 EORI、是否愿意承担进口与产品合规责任 |
| 报关代表 | 是直接代表还是间接代表；由谁提供商品编码、价值、原产地与许可证资料 |
| 承运人／货代 | 谁提交入境安全与安保数据，何时需要补充运单、舱单或其他运输信息 |

别把“欧洲仓”或“平台仓”当作进口主体。仓库地址不等于进口商，平台也未必替卖家承担申报和产品合规责任。

## 报关资料怎样填，才不会前后矛盾

下面这张表是卖家交资料给欧盟进口商或报关代表时的底线。具体字段、代码和系统因进口国与程序而异，申报前仍要以当地海关和报关代表的要求为准。

| 文件或数据 | 应写什么 | 常见错误 |
| --- | --- | --- |
| 商业发票 | 买卖双方完整名称与地址、发票号和日期、真实成交币种与金额、逐项品名、数量、单价、贸易术语、原产地 | 用“样品”“杂货”“配件”等笼统品名，或低报价格 |
| 装箱单 | 每箱包装号、每个 SKU 的数量、毛重、净重、外箱尺寸和总箱数 | 与发票数量、运单件数不一致 |
| 商品描述与编码 | 可识别的材质、功能、用途、型号和品牌；由进口商／报关代表据此核对 HS／CN／TARIC 编码 | 先按低税率编码报价，后用产品照片补解释 |
| 原产地资料 | 非优惠原产地与任何优惠原产地证明应一致，并能追溯生产地 | 把发货地当作原产地，或把供应商口头承诺当证明 |
| 运输文件 | 运单、提单或航空运单上的收发货人、件数、重量与箱单对应 | 收件人和进口申报主体完全不同且无授权链 |
| 产品合规文件 | 适用品类的 EU 符合性声明、技术文件、测试报告、标签／说明书、欧盟责任人信息及专项许可 | 只发一份过期报告，型号、工厂或批次对不上 |

## 填写时盯住三件事

1. **品名写到可核验：** “额定 20 W、室内用 LED 台灯，型号 X”比“灯具”或“电子产品”有用。品名应能支撑编码和监管判断。
2. **金额回到交易本身：** 发票、付款记录、合同或订单、平台成交记录要能解释同一笔交易。为少交税而让报关价值脱离成交价格，后面很难补救。
3. **所有文件共用型号：** 发票、箱单、标签、说明书、测试报告和符合性声明，应能落到同一型号或明确的型号系列。抽查时找不到这个连接点，解释会很被动。

## 哪些产品需要再加一层资料

**受 CE 规则约束的产品：** 部分电器、玩具、机械和个人防护用品在此列。除申报资料外，还要按适用法规准备符合性评估、EU 符合性声明、技术文件、标识和说明书。

**食品接触材料：** 塑料杯、餐盒、保鲜盒都应核实材料规则、迁移测试、书面合规声明和用途限制。“食品级”几个字不能代替文件。

**化学品、电池、木制品、动植物产品及配额或许可证货物：** 还可能涉及 REACH、危险品运输、检疫、木材、环境或专项进口许可。订舱前，用商品编码和目的国在欧盟官方数据库核对一次。

## 中小企业行动清单

1. 打样阶段就给每个 SKU 建档，记录型号、材质、用途、工厂、图片、适用法规和责任人。
2. 报价前写清进口模式：谁是欧盟进口商，EORI 谁提供，谁委托报关代表，税费谁承担。
3. 装运前逐项比对商业发票、装箱单和运单草稿的品名、型号、数量、重量、收发货人和贸易术语。
4. 申报前把产品资料连同发票和箱单交给进口商或报关代表，留出核对和补件时间。
5. 货被扣留时，先记下海关或主管部门援引的法规、货物项次和期限，再判断下一步。
